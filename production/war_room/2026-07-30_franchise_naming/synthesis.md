# The Decree

**Ruling:** "Hell of Duty" (and "Hell of Duty: Vietnam") is **rejected as a ship name**, for the project and for the franchise umbrella. It stays what it always was — the internal joke that got the idea moving. Two independent lines of reasoning kill it on their own: it primes players for the exact arcade/rails identity the five pillars reject, and it carries real trademark exposure that compounds across every future era-tagged title instead of resetting per game.

**Kept, because it's genuinely good:**
1. **The franchise-umbrella structure** — one base brand, era-tag subtitle per title (Vietnam / Korea / WWI). This matches how TerrainEngine is already built (swappable real-world elevation data + presets per region) and is a proven shape in the genre. Nothing here needs to change.
2. **"Hell" as the tonal anchor.** It's earned across all three planned settings, it was never the borrowed half of the pun, and it should survive into whatever the eventual base name becomes.

**Standing decree status:** the 2026-07-28 "name stays RECON" ruling is **not superseded** by this session. No replacement name was adopted today. RECON remains the working project name until a specific, vetted replacement clears its own War Room pass.

**Next actionable steps (recorded):**
1. Run a dedicated naming-brainstorm pass — base name candidates that keep "Hell" as root, drop the "of Duty" construction, work as an umbrella across Vietnam/Korea/WWI.
2. Before Caleb gets attached to any candidate, run an informal trademark screen (USPTO TESS / TMview) — Devil's Advocate's condition, non-negotiable given the franchise stakes.
3. Once a name clears both, bring it back to a War Room session to formally supersede the 7/28 decree — explicit record, not drift.

**What was sacrificed:** the marketing hook of a catchy, instantly-repeatable pun. Traded for legal safety and a name that will actually read as its own identity three titles from now instead of a joke about someone else's franchise.
