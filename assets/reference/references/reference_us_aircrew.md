# US Vietnam Aircrew Reference (1965-1972)

Two pilot models. They differ far more than expected — build both, don't reskin one.

## Type 1 — Helicopter crew (UH-1 Huey, AH-1 Cobra, OH-6)

| Item | Spec | Notes |
|---|---|---|
| Helmet | **SPH-4** (1970+) / APH-5 (earlier) | **Huge protruding earcups** (~95mm dia, 40mm proud). Brow visor shelf projects 15-20mm. Single smoke visor. |
| Comms | Boom mic on swan-neck arm, **left earcup** | ~130mm arm, 25mm capsule at jaw. NO oxygen mask. |
| Flight suit | OG-106 Nomex one-piece (1969+), K-2B cotton before | Browner/yellower than fatigue OG-107. |
| Body armor | **"Chicken plate"** — MIL-C-43544 | Curved convex ceramic slab. Pilots: front plate only, mesh back. Gunners: front+back. ~330w x 400h x 22mm. **Outermost torso layer.** |
| Survival vest | SRU-21/P, worn UNDER the plate | Mostly hidden. Model only the collar. |
| Harness / G-suit | **NONE** | No ejection seat. Torso unbroken by webbing. |
| Sidearm | S&W M15 .38 | **Low-slung thigh rig** (buscadero) or shoulder holster. |
| Gloves | GS/FRP-2 | Sage Nomex back, tan sheepskin palm. |
| Boots | Jungle boot | Black leather foot, olive nylon shaft. |

**Silhouette: wide lumpy head, flat block chest, plain legs.**

## Type 2 — Fixed-wing pilot (F-4, F-105, A-1)

| Item | Spec | Notes |
|---|---|---|
| Helmet | **HGU-2A/P** | Smooth sphere hugging skull. **No earcups.** Bayonet receivers on each cheek. |
| Oxygen mask | **MBU-5/P** | Green rubber + green ABS shell. Hangs from ONE cheek clip, swings outboard; corrugated hose loops across chest. On-face for flying pose. |
| Flight suit | CWU-27/P sage Nomex | Thigh pockets hidden by G-suit — omit. |
| Body armor | **NONE** | Chicken plate is for aircraft without ejection seats. |
| Survival vest | SRU-21/P, **outermost** | Mesh, bulging pockets, PRC-90 radio + antenna, knife hilt. Black leather holster high on left chest. |
| Harness | **PCU-15/P torso harness** | Shoulder straps + chest strap = H/A pattern on chest. **Koch fittings ~60x50mm metal blocks at each shoulder.** Leg loops through crotch. |
| G-suit | **CSU-3/P** over flight suit legs | Vertical pleat seams. **Cutout windows at knees + crotch** (two-tone knee). Black hose stub at LEFT hip. |
| Sidearm | S&W M15 .38 | Shoulder-holster position on vest, high left chest. |
| Boots | All-black leather | |

**Silhouette: round head with a green snout, cluttered chest, banded legs.**

## Sprite-scale cues, ranked (survive to 32px)
1. **Head width** — SPH-4 earcups make the head ~35-40% wider. HGU-2A/P is a clean sphere.
2. **Chest** — smooth slab (helo) vs. irregular clutter + shoulder Koch blocks (jet).
3. **Face** — green mask snout + dangling hose (jet) vs. thin boom stick (helo).
4. Legs — plain coverall vs. banded G-suit with knee cutouts.
5. Holster — thigh (helo) vs. chest (jet).

If only three fit: **earcups, chest slab vs clutter, mask snout.**

## Door gunner variant
Type 1 mesh + front-AND-back plate (solid back, slab reads from rear too) + no holster + M60.

## Date discipline
For one model covering the whole span, build **late-war (1970-72)**: SPH-4 + Nomex (Army), HGU-2A/P + CWU-27/P (USAF).
